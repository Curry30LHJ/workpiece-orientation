离线版工件正反面检测使用说明

版本：1.0.0

1. 版本选择
GPU 版需要支持 CUDA 的 NVIDIA 显卡及驱动；没有 NVIDIA 显卡请使用 CPU 版。两版不能混用运行时文件。

2. 安装与启动
将 ZIP 解压到任意本地文件夹，双击 WorkpieceOrientation.exe。首次启动不会自动复制旧数据。

3. 首次建立工件库
在程序中创建工件并按提示采集模板。运行数据位于 data 文件夹，其中 workpieces 保存工件库，rules 保存规则，cache 保存缓存，logs 保存日志。

4. 备份、复制与更新
复制前必须退出程序。仅复制需要的 data 子目录并保留目录结构；非空 data 根目录不能与另一版本合并，请先完整备份后选择一个来源。更新时解压新版本到新文件夹，再按需复制数据。

5. 日志与常见错误
日志位于 data\logs。启动失败通常由 GPU 驱动缺失、误用 CPU/GPU 版本、杀毒软件拦截或文件未完整解压造成；请检查对应驱动并重新解压完整 ZIP。

6. 卸载
关闭程序后直接删除整个解压文件夹即可。需要保留数据时，先备份 data 文件夹。
