## 批量结果联动

- 每条批量结果保存图片绝对路径、工件 ID、完整预测响应、标签、复检标记、耗时和处理状态。
- 批量表格固定为文件、结果、复检、耗时、状态五列，不再为每行重复创建确认按钮。
- 点击任意已完成行会同步更新左侧图片、当前文件名、检测结果和右侧完整证据。
- 批量继续返回结果时不会覆盖操作员手动选择的行；批量完成后优先定位第一条建议复检且未处理的结果。
- 汇总区显示正面、反面、不确定、建议复检、已处理和未处理数量；中途失败显示完成数量、失败文件和原因。
- 重新选择批量图片会同时清除旧表格、旧预览、旧证据和旧确认上下文。

## 确认状态机

- 单图和批量结果共用“确认正面并入库”“确认反面并入库”“不入库”三个全局按钮。
- 批量确认请求携带所选结果自己的工件 ID 和图片路径，异步回复精确更新发起请求的行。
- 成功后状态更新为“正面已排队”或“反面已排队”，并自动前进到下一条建议复检/未处理结果。
- “不入库”只修改本地处理状态，不调用后端，并自动前进。
- 提交失败保留当前行和错误状态，可再次尝试；已处理行不能重复提交。

## 异常与安全门

- 批量检测未完整结束时可以查看已完成结果，但三个确认按钮保持禁用。
- 批量启动后所有图片始终使用启动时锁定的工件 ID；检测过程中切换下拉框不会改变后续请求目标。
- 当前工件与批量来源工件不一致时保留图片和证据、禁用确认并显示原因；切回原工件后恢复处理能力。
- 后端断连时保留批量结果、当前图片和证据；确认请求途中断连会将对应行标为“提交失败”，并提示入库结果未知，不自动重发。
- 批量中途预测失败后保留已完成行，且整批确认入口保持禁用。
- 图片无法读取时先清除旧像素，再显示包含文件名的错误提示。
