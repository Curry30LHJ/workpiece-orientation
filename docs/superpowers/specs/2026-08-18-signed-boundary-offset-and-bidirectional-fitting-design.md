# 有符号边界偏移与正反面独立拟合设计

## 1. 目标

将几何规则的“安全边距”改成与忽略方向无关的有符号边界偏移，并明确正面、反面分别拥有自己的参考模板、基准边界和拟合结果。

本次变更只调整几何规则编辑、持久化兼容和边界掩膜计算，不修改 PP-ShiTuV2、ALIKED、LightGlue、特征融合或现有阈值，也不需要重新训练模型。

## 2. 已确认语义

规则仍保留 `mode`：

- `inside`：忽略拟合边界内部；
- `outside`：忽略拟合边界外部。

`margin_ratio` 改为有符号百分比，应用于几何边界本身：

```text
effective_boundary = fitted_boundary * (1 + margin_ratio)
```

- `+2%`：边界向外扩大 2%；
- `-2%`：边界向内收缩 2%；
- `0%`：使用拟合边界。

偏移只改变边界的尺寸，不改变拟合得到的中心点和旋转角度。持久化的
`geometry` 仍保存未偏移的原始拟合结果，偏移后的边界只在生成忽略掩膜和
界面预览时计算。

对椭圆，横轴和纵轴分别乘以同一比例；对旋转矩形，半宽和半高分别乘以同一比例。边界偏移不会参与候选边缘搜索。实现时必须把候选排序使用的内部搜索容差与 `margin_ratio` 分离；候选搜索继续使用拟合器自身的搜索范围和种子距离评分，改变 `margin_ratio` 的符号不得改变候选集合或默认候选索引。

因此：

- `inside +2%` 会扩大被忽略的内部区域；
- `outside +2%` 会把外部忽略起始边界向外推，实际忽略的外部区域变少；
- `outside -2%` 会把边界向内收，实际忽略的外部区域变多。

有效范围保持与当前校验一致，为 `[-0.94, 0.94]`；Qt 默认值为 `0%`，步长为 `1%`，显示正负号和百分号。

## 3. 正反面独立拟合

正面和反面各自维护：

- `reference_template`；
- `anchor`；
- 规则的像素种子和对象相对几何；
- 候选列表、选中候选和拟合诊断；
- 有符号边界偏移。

切换模板或方向时：

1. 清除上一张图的拟合线、候选下拉框和诊断文本；
2. 当前方向有有效种子时，自动对新模板发起只读预览；
3. 预览响应只更新当前模板对应的拟合覆盖层和诊断；
4. 不允许将正面拟合结果作为反面结果显示或写入。

复制规则到另一方向只复制名称、形状、忽略模式和边界偏移。目标方向进入 `needs_reseed` 且停用状态；操作员在目标方向重新粗画边界并完成预览后，系统才写入目标 anchor、对象相对几何并启用规则。

在 `needs_reseed` 状态下，目标方向旧的 `anchor`、`geometry`、候选和预览
均视为无效；即使这些字段暂时保留在草稿中，也不得参与预览、验证、发布或
界面绘制。重新预览成功后才一次性替换这些字段。

当前工件库中反面 `anchor=null`、规则停用且 `needs_reseed` 的状态应被明确显示为“待重新标定”，不再显示正面遗留的绿色拟合线。

## 4. 数据兼容与迁移

现有规则增加可选字段：

```json
{
  "margin_ratio": 0.02,
  "margin_semantics": "signed_boundary_v2"
}
```

缺少 `margin_semantics` 时按旧版语义读取：

- 旧 `inside` 的非负边距转换为同值正数；
- 旧 `outside` 的非负边距转换为相反数，以保持原有掩膜行为。

当前旧版在省略 `margin_ratio` 时的默认值是 `0.02`，因此缺少语义标记且
缺少该字段的旧规则也必须先按旧默认值迁移；新建规则显式写入
`margin_semantics` 并以 `0.0` 为默认值。出现未知的语义标记或负数旧值时
拒绝迁移并给出错误，不得静默猜测。

保存草稿或发布时写入 `margin_semantics: "signed_boundary_v2"`，避免重复迁移。旧版 5+5 工件库、无几何规则工件库和旧位置遮罩缓存继续可恢复；在新几何版本发布前继续使用旧活动缓存。

迁移只改变边界偏移的解释，不改变规则形状、对象相对几何、方向标签或模板文件。

## 5. 界面行为

原“安全边距”控件改名为“边界偏移”，并提供简短提示：

```text
负值向内收缩，正值向外扩张；仅影响最终忽略边界，不改变候选搜索范围。
```

界面同时显示当前方向和模板的拟合状态：

- 未配置：没有 anchor 或规则种子；
- 待重新标定：复制来的规则尚未在当前方向完成预览；
- 预览中：等待当前模板候选结果；
- 已拟合：显示选中候选、边缘支持、残差、边界尺寸和偏移后的最终尺寸。

正反面边界差异不作为错误自动合并。只有当某一方向没有可用 anchor、候选不足或拟合低置信度时，才报告该方向需要复核。

## 6. 后端接口与错误处理

现有 `preview_geometry_mask_rule` 请求继续接收 `margin_ratio`，但该值必须是带符号的浮点比例。预览响应额外返回：

- 原始拟合边界；
- `margin_ratio`；
- 偏移后的显示边界；
- 当前方向、模板标识和参考模板尺寸。

原始拟合边界和偏移后的显示边界使用不同字段返回，前端不得用上一次
模板的显示边界补齐缺失响应。

`needs_reseed` 只禁止使用该方向旧的 anchor、geometry 和活动遮罩，不能阻止
操作员用新种子发起一次只读预览；预览成功后才把该方向切换为 `ready`。候选
拟合失败、图片不可读或新种子无效时，不生成部分遮罩，不保留上一模板的覆盖层，
并返回明确状态。发布校验继续按现有规则阻止未复核的低置信度模板。

## 7. 测试与验收

Python 测试：

- `inside` 的 `-2%/0/+2%` 分别产生收缩、原尺寸、扩张掩膜；
- `outside` 的 `-2%/0/+2%` 按同一几何偏移公式工作；
- 旧版内部/外部正边距迁移后掩膜结果保持不变；
- 缺少旧版 `margin_ratio` 时按旧默认 `0.02` 迁移，新建规则默认 `0.0`；
- 正面和反面使用不同 anchor、参考模板和边界偏移时互不污染；
- 反面 `needs_reseed` 时不产生活动拟合结果；
- 候选搜索不受边界偏移符号改变影响。

Qt 测试：

- 边界偏移控件可以输入负数、零和正数；
- 切换模板或方向会清空旧拟合覆盖层、候选和诊断；
- 有效种子会触发当前模板预览；
- 反面待重新标定时显示明确状态，不显示正面旧结果。

验收标准：操作员可以明确控制边界向内收缩或向外扩张；正面和反面分别重新拟合后，界面显示的绿色边界始终属于当前方向和当前模板；旧工件库行为不变。
