# 局部 SIFT 匹配验证设计

## 目的

验证局部特征及几何一致性是否能改善 `1_M1` 中 PP-ShiTuV2 全局特征的正反面误判；同时在 `1_M2` 与 `1_M7` 上检查是否引入回退。

## 范围

- 固定每个标签随机抽取 5 张模板，沿用当前随机种子 `20260813`。
- 仅使用已安装的 OpenCV SIFT 与 RANSAC；不下载模型、不训练。
- 首版使用图像中心的可配置矩形区域，排除边缘背景及可能从角落进入的其他工件。
- 对查询图与每张正、反面模板提取 SIFT 特征，以 KNN 比率筛选后使用 RANSAC 单应性验证。
- 每个模板对的分数由 RANSAC 内点数及内点覆盖范围组成；标签分数取该标签模板对的最高分。
- 当两面分数相等、最佳分数不足，或分差不足时输出 `uncertain`，不强制输出正反面。
- 生成汇总结果与 M1 误判/不确定样本的匹配可视化。

## 成功标准

1. 在 M1/M2/M7 上可重复执行且不会读取测试图作为模板。
2. 报告每类的准确率、误判数、不确定数、混淆矩阵和模板文件名。
3. M1 的结果能与既有 PP-ShiTuV2 5+5 基线（155/177，87.57%）直接比较。
4. 输出的局部匹配图能显示 RANSAC 保留的对应点，以便人工判断其是否落在工件判别特征上。

## 后续决策

- 若 SIFT 对 M1 有明显提升且匹配点落在有效特征区域，再将同一接口替换为 ALIKED + LightGlue。
- 若稳定特征点不足或集中在反光、背景处，则优先试验补光与人工确认 ROI，而非训练分类器。
