# 几何干扰规则编辑器重设计

## 1. 背景与目标

当前 `GeometryRuleCanvas` 对圆、椭圆和旋转矩形都使用同一种“左上角到右下角”的矩形拖拽手势。对圆而言，这会把拖拽框的中心误认为圆心，导致操作员很难画出合适的内圆；对旋转矩形而言，旋转角还需要依赖旁边的数值控件。与此同时，管理器把“基准边界”作为一个必须单独绘制的对象，增加了操作步骤，也容易让操作员误以为需要精确标出工件外轮廓。

本设计把编辑器改成“形状专用手势 + 粗略种子 + 当前模板自动拟合”的工作流：操作员只需在一张干净参考模板上大概指出要忽略的几何边界，系统再为每张模板独立寻找真实边界。对象相对坐标、几何遮罩、版本发布、PP-ShiTuV2/ALIKED/LightGlue 和现有融合阈值保持不变。

## 2. 范围与非目标

### 2.1 本次范围

- 重做 Qt 画布的形状绘制手势、缩放/平移、手柄编辑和数值微调。
- 取消“必须先单独画基准边界”的主流程；首次创建规则时自动推断当前方向的外部基准边界，并允许在推断失败时使用备用手动基准操作。
- 保存人工种子和自动拟合结果，使管理窗口能同时显示两者。
- 为后台拟合结果返回有限候选、置信度、边缘支持和选择的候选编号。
- 在每张模板上独立拟合；低置信度默认阻止发布，单张模板只能复核/排除，不能形成隐性模板专属规则。
- 保留正反面独立配置、可选复制、草稿/发布/回退、撤销/重做和旧版本兼容。

### 2.2 非目标

- 不实现自由曲线或自由多边形。
- 不训练新的反光/阴影分类模型，也不微调现有模型。
- 不改变 PP-ShiTuV2、ALIKED、LightGlue、局部/全局融合和既有阈值。
- 不把旧位置递推标注静默转换成新的几何规则。

## 3. 用户工作流

### 3.1 参考模板与方向

正面和反面分别选择一张干净参考模板。规则在两个方向上独立维护；复制到另一方向是显式操作。复制只带过去规则名称、形状、内部/外部语义和安全边距，目标规则进入“待重画”且停用，必须在目标方向重新绘制种子、自动拟合并验证后才能启用。

### 3.2 形状工具

第一版提供三个同等地位的工具：圆、椭圆、旋转矩形。没有默认主工具。

- 圆：第一次按下确定圆心，拖动确定半径，释放完成。
- 椭圆：按下确定中心，拖动到外接框角点，同时确定两个半轴；完成后分别用水平/垂直轴手柄调整半轴，角度通过旋转手柄或数值框微调。
- 旋转矩形：按下确定中心，拖动确定半宽/半高；完成后出现旋转手柄，拖动或数值框调整角度。

所有形状都支持选中后拖动中心、边界手柄和旋转手柄。参数变化即时写入草稿内存，并在画布上显示虚线种子。`Esc` 取消当前手势；`Ctrl+Z`、`Ctrl+Y`、重置和删除作用于草稿历史。滚轮缩放、中键平移，`R` 将视图复位到整图。

### 3.3 粗略种子与自动拟合

操作员绘制的是“语义种子”，而不是最终像素边界。规则编辑器以参考模板中的最大闭合主体轮廓、画面中心先验和种子形状作为候选来源，自动寻找外部基准边界；成功后把该边界作为隐藏的对象坐标系来源，并将规则种子转换成对象相对几何。外部规则若与该候选边界重合，可以直接复用同一个拟合结果。若自动推断失败，界面显示明确失败原因，允许执行备用“手动指定基准”操作；手动指定只是故障兜底，不恢复为每次都必须先画基准的主流程。

对每张模板，系统重新寻找基准和每条启用规则的真实边界，不复用上一张图的像素坐标。系统返回有限数量的候选（默认最多 3 个），按边缘支持、可见比例、拟合残差和与种子距离排序；默认选最高质量候选，但界面必须允许查看并切换候选，不能静默接受低质量结果。

圆形内腔使用“忽略内部”，外部侵入使用“忽略外部”；通用内部/外部下拉框继续保留。多个启用规则按忽略区域并集处理。

### 3.4 结果与发布

画布同时叠加：

- 青色虚线：参考模板中的人工种子；
- 绿色实线：当前选中模板自动拟合出的边界；
- 橙色半透明层：最终忽略区域。

右侧显示当前模板、候选编号、置信度、边缘支持、可见比例、残差、覆盖率和耗时。验证任务在后台执行，显示当前方向、当前模板/总模板数和总耗时，并允许取消。取消或失败只保留草稿和已有报告，不切换活动版本。

低置信度默认阻止发布；操作员必须明确覆盖并填写原因。某张模板拟合失败时可标记为“复核”或“从本几何版本排除”，且必须填写原因。“复核”继续阻止发布；“排除”只把该模板从当前几何版本的候选缓存中排除，不从工件库和基线缓存删除。任一方向排除后没有可用模板时禁止发布。规则种子修改会让所有模板重新拟合，禁止单张模板直接保存另一套隐藏规则。

草稿有脏状态。只有点击“保存草稿”才写入后端；关闭时若有未保存修改必须确认。“重新载入已保存草稿”会丢弃本地未保存修改并恢复最近一次后端快照。活动版本可作为只读叠加层查看；若要修改活动版本，必须显式复制为草稿。发布、回退和预测使用的 revision 在窗口内始终可见。

## 4. 数据与兼容性

现有 `geometry_masks` 文档格式继续作为持久化边界，新增字段均为可选，以兼容已发布的旧几何档案：

- 方向对象新增 `reference_template`，记录参考模板稳定标识、原图尺寸和来源方向。
- 方向对象新增可选 `template_reviews`，按稳定模板标识记录 `included/review/excluded` 状态和非空原因；缺失时所有模板均为 `included`。
- 方向对象的 `anchor` 增加 `mode: "auto"`；旧档案没有该字段时按旧的手动/已有 anchor 读取。
- 每条规则保留现有对象相对 `geometry`，并可增加 `seed_geometry`，用于重新显示人工种子；缺失时用 `geometry` 作为兼容显示。
- 每条规则新增可选 `editor_state: "ready" | "needs_reseed"`；缺失时视为 `ready`，`needs_reseed` 必须同时为停用状态且不得参与验证或预测。
- 验证报告的每张模板项增加 `candidates`、`selected_candidate_index`、`fit_duration_ms`、`review_state` 和 `review_reason`。
- 活动版本继续由 `active_revision` 指向不可变 revision；编辑器历史只存在当前 Qt 草稿内，不写入生产预测路径。

旧版 5+5 工件库、没有几何规则的工件库以及带有旧 `interference_groups` 的工件库必须继续恢复。旧位置标注仅以归档/只读方式显示，不参与新的自动几何拟合，也不被转换成圆、椭圆或旋转矩形。在新几何版本发布前，旧库继续使用原先已经生效的预测缓存；发布新几何版本后，新版本原子取代旧位置遮罩成为该工件的活动规则。回退必须能够恢复发布前的稳定预测缓存。

## 5. 模块边界与接口变化

### 5.1 Qt `GeometryRuleCanvas`

保留现有 JSON 形状字段（`shape`、`cx`、`cy`、半径/轴/半宽高、`angle_deg`），增加内部手势状态和视图变换，不让管理器拼装鼠标几何。公开行为包括：

- `setImage`, `setTool`, `setCoarseShape`, `setFitOverlay`；
- `resetView`, `cancelGesture`, `setNumericShape`；
- `shapeChanged(shape)`；
- 可选的 `candidateSelected(index)` 和 `viewChanged(scale, offset)` 信号。

画布负责把 widget 坐标转换成原图像素坐标；管理器负责把原图像素种子转换成对象相对坐标。

### 5.2 Qt `GeometryMaskManagerDialog`

管理器负责方向、参考模板、规则列表、内部/外部模式、边距、草稿历史、验证进度和发布确认。删除“将画布设为基准边界”作为默认流程，改为显示自动基准状态和“手动指定基准”备用按钮。管理器不直接读写 profile 文件，只通过现有 snapshot/save/validate/job/publish/rollback 信号与后端交互。

### 5.3 Python `GeometryCalibrator`

保持 `GeometryCalibrator.fit(image, direction_profile)` 兼容调用，并扩展返回字段：

```python
{
    "status": "active" | "low_confidence" | "unavailable" | "unreadable",
    "anchor": {...},
    "rules": [{
        "rule_id": str,
        "status": str,
        "fitted_shape": {...},
        "candidates": [{"shape": {...}, "score": float,
                        "edge_support": float, "visible_ratio": float,
                        "fit_residual": float}],
        "selected_candidate_index": int | None,
        "fit_duration_ms": float,
    }],
    "ignore_mask": np.ndarray | None,
}
```

当 `anchor.mode == "auto"` 时，标定器从当前图像和参考种子搜索外部基准；当自动搜索失败且请求明确包含手动备用 anchor 时，才使用备用值。任何启用规则不能可靠拟合时，整个方向返回非 active，调用方不应用部分遮罩。

### 5.4 TCP 与后台任务

新增一个只读命令 `preview_geometry_mask_rule`，解决取消独立基准绘制后的坐标转换问题。请求包含 `workpiece_id`、`base_library_revision`、`direction`、`template_id`、原图像素坐标的 `seed_shape`、`mode`、`margin_ratio`，以及可选的 `anchor_candidate_index`/`rule_candidate_index`。响应返回：

- 自动基准的候选、选中编号和最终基准；
- 当前规则的候选、选中编号和拟合边界；
- 可直接写入草稿的对象相对 `geometry`/`seed_geometry`；
- 置信度、边缘支持、可见比例、残差和拟合耗时。

画布只在完成一次手势或切换候选时请求预览，不在每个鼠标移动事件上发送 TCP 请求。该命令不写 profile、不构建模板缓存、不分配 `operation_id`；库 revision 或模板标识不匹配时拒绝预览。

其余流程沿用现有 `get_geometry_mask_profile`、`save_geometry_mask_draft`、`validate_geometry_mask_draft`、`get_geometry_mask_validation_job`、`geometry_mask_validation_job_action`、`publish_geometry_mask_profile` 和 `rollback_geometry_mask_profile` 命令。只扩充 snapshot/report 的可选字段，不改变旧客户端必需字段。验证任务按模板粒度更新进度，后端重启中的任务变为 `interrupted`。

## 6. 错误处理与安全策略

- 图片不可读、尺寸过小或候选不足：当前模板标为 `unreadable`/`low_confidence`，不给出活动遮罩。
- 候选置信度低：默认不可发布；覆盖必须有原因并记录 `operation_id`、操作者和时间。
- 正面或反面任一方向存在失败启用规则：整张查询都不应用几何遮罩，正反两个方向同时回退到原始基线特征，不混用单边或部分遮罩，并返回 `needs_review: true`。
- 草稿、工件库 revision 或验证任务指纹陈旧：拒绝保存/发布并要求刷新，不覆盖较新的状态。
- 自动基准失败：保留草稿，提示“自动基准未找到”，允许显式手动备用操作。
- 发布原子替换失败：活动 revision、manifest 和运行时缓存保持原状。

## 7. 测试与验收

### 7.1 Qt 单元测试

- 圆心—半径、椭圆双轴、旋转矩形旋转手势产生正确 JSON；拖动方向不影响中心和正尺寸。
- 画布缩放、平移、复位后，同一原图像素仍对应同一形状坐标。
- 手柄编辑、数值微调、`Esc`、撤销/重做、重置和删除状态正确。
- 虚线种子、绿色拟合边界、橙色忽略层同时显示；候选切换只改变拟合层。
- 自动基准失败时显示备用手动按钮；旧档案没有新字段时仍能打开。
- 关闭未保存草稿会提示；发布/回退按钮按验证状态和覆盖原因启用。

### 7.2 Python/TCP 测试

- 圆形内腔在工件平移、旋转、尺度变化以及中心反光位置变化时重新拟合；不使用上一次图片坐标。
- 外部圆规则忽略外部侵入但保留安全边距内工件区域；椭圆和旋转矩形在旋转图上保持正确。
- `preview_geometry_mask_rule` 把参考模板像素种子转换成对象相对几何，切换候选不修改持久化档案，陈旧库 revision 被拒绝。
- 每张模板返回候选和选中编号；低置信度、不可读图、可见弧不足时不产生部分遮罩。
- 1+1、5+10、10+15 及超过 30 张模板的验证任务能完成并按模板报告进度。
- 旧 5+5 工件库和带旧位置递推数据的库能恢复；发布新几何版本前继续使用旧稳定预测缓存，发布后由新几何版本原子取代。
- 后台验证可取消、重启后状态为 `interrupted`，陈旧 revision/重复操作号被拒绝。
- 现有全量 Python 测试、Qt Release 构建和 offscreen Qt 测试全部通过。

## 8. 验收标准

操作员无需精确画圆，只需用中心—半径手势圈出大致内圆，就能在管理窗口看到每张模板自动拟合出的真实内圆和忽略覆盖层；中心反光位置改变或四周出现侵入工件时，几何规则不依赖固定像素位置。自动拟合失败不会悄悄污染预测，界面能指出具体模板、候选和原因。旧工件库继续可用，且未修改既有识别模型、融合阈值和训练流程。
